# LearnHub – Online Learning Platform

LearnHub is a responsive and animated **frontend e-learning website** built using **HTML, CSS, and basic JavaScript concepts**.  
The project focuses on clean UI design, smooth animations, and responsive layouts to provide a modern learning platform experience.

---

## 🚀 Project Features

- Responsive design for desktop, tablet, and mobile
- Modern UI with clean layout and spacing
- Animated hero sections and cards
- Course listing with hover effects
- About page with team information
- Contact page with contact form
- Notification button with badge
- Font Awesome icons integration
- Smooth CSS transitions and keyframe animations

---

## 🧑‍💻 Technologies Used

- **HTML5** – Page structure and content  
- **CSS3** – Styling, layout, animations, and responsiveness  
- **Font Awesome** – Icons (notification bell, contact icons)  

> No backend is used in this version.  
> The project is frontend-only and can be connected to APIs or backend services later.

## ✨ Animations Used

- Fade-in and slide-up animations for sections
- Floating animation for hero images
- Pop and bounce effects for statistics
- Hover effects for buttons and cards

All animations are implemented using **pure CSS keyframes and transitions**.

---

## 📱 Responsive Design

- Flexbox and CSS Grid used for layouts
- Media queries for smaller screen sizes
- Works well on mobile, tablet, and desktop devices

---

## 🔧 How to Run the Project

1. Download or clone the repository  
2. Open `index.html` in any modern browser  
3. Navigate through pages using the navbar  

No installation or server setup required.
